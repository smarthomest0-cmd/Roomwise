# Roomwise
Home Assistant app that builds a dashboard from your own **areas and floors**. Nothing to configure.
- Rooms come from your Areas; each room gets only the tabs it needs (Lights, Shades, Comfort, Media, Security, Power, More).
- Edit mode hides rooms or devices; choices are saved in the app's `/data`.
## Install
Settings → Apps → App Store → ⋮ → Repositories → add your GitHub URL → install Roomwise → Show in sidebar.
